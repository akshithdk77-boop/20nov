# For Sevanthi · My Aishu ♡

A dreamy rainy-evening birthday experience for Sevanthi (Aishu), built with **HTML, CSS and JavaScript**. It uses misty blue-grey skies, blush-pink lighting, soft rain, floating hearts, cursor sparkles and a long sequence of interactive surprises.

## Open the website

1. Extract `Sevanthi_Birthday_Surprise.zip`.
2. Open the extracted `sevanthi_birthday_surprise` folder.
3. Double-click `index.html` to open it in Chrome or Edge.
4. For the best experience, use a recent version of Chrome or Edge.

You can also open the folder in VS Code and use the **Live Server** extension.

## Gallery photos

The nine photos in **Holding Hands Together** are stored permanently in `assets/images`.
Click any photo to view it larger.

## Permanent soundtrack

The six songs in **Our little soundtrack** are stored permanently in `assets/music`.

## Personalize the message

Open `index.html` and edit the text in the **A little letter for you** section. You can also change the messages in the gift surprise directly in the `giftReveal` section.

## New extended experience

- Rain-kissed pink and misty blue-grey visual theme with animated rainfall behind the page
- Rainy-window illustration with a button that sends a fresh wish each time
- Four interactive “Open when…” letters for missing someone, needing a smile, feeling tired, and birthday wishes
- A six-star clickable constellation, with a unique wish hidden behind every star
- A “100 little reasons” surprise: tap to reveal another reason each time
- A future-date ticket with a hidden date-plan reveal
- Three replayable mini-games: a shuffled matching game, a timed heart-catching challenge, and a birthday-surprise quiz

## Features

- Cinematic rainy pink, lilac and mist visual theme
- Animated opening birthday screen with softly falling hearts
- Floating hearts, soft ambient glows, cursor-following hearts and touch sparkles
- Responsive layout and mobile navigation
- Permanent nine-photo gallery with lightbox preview
- Interactive gift reveal with heart burst
- Animated virtual hug
- Six-song soundtrack with a custom audio player
- Personal birthday letter and animated closing section
- Extended scroll experience with multiple sections and repeatable surprises
- Reduced-motion accessibility support

## Notes

- Photos and music are stored in the local `assets` folder and are not uploaded to a server.
- Google Fonts are loaded online. If you are offline, the page falls back to system fonts.
- No framework, installation, build step, or backend is required.
